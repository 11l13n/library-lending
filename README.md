# Учёт выдачи книг в библиотеке

Учебный проект по дисциплине «Технологии разработки приложений на базе фреймворков».

## Назначение

Программа помогает библиотекарю вести каталог книг, учитывать читателей,
выдавать книги и оформлять возврат. Каждая запись каталога представляет один
физический экземпляр книги. Книга доступна для выдачи, если у неё нет
незавершённой выдачи.

## Целевая аудитория

Библиотекарь небольшой библиотеки.

## Основные сущности

- **Книга:** идентификатор, название, автор.
- **Читатель:** идентификатор, имя, номер читательского билета.
- **Выдача:** идентификатор, книга, читатель, дата выдачи и дата возврата.

## Планируемые функции

- Добавление книг и читателей.
- Просмотр каталога и поиск книг.
- Проверка доступности книги.
- Выдача книги читателю.
- Оформление возврата.
- Просмотр текущих выдач и статистики.

## План развития

1. **ПР1:** простые функции, начальный сценарий, отладка.
2. **ПР2:** консольное меню, коллекции, модули, JSON, исключения, pytest и flake8.
3. **ПР3:** классы книги, читателя и выдачи; адаптация JSON и тестов.
4. **ПР5:** Django-проект, маршруты и первые веб-страницы.
5. **ПР6:** шаблоны Django, общий макет, CSS, изображение и JavaScript.
6. **ПР7:** SQLite, перенос JSON, SQL-запросы, поиск и статистика на сайте.

Дальнейшие этапы курса: Django ORM, пользователи, API и контейнеризация.
